# goit-algo-hw-10

## Завдання 1 — оптимізація виробництва

- `task-1.py` використовує PuLP для моделювання випуску лимонаду та фруктового соку.
- Змінні: кількість кожного напою; мета — максимізувати сумарне виробництво за наявних запасів води, цукру, лимонного соку та фруктового пюре.
- Після запуску скрипт друкує оптимальний план (в нашій задачі: 30 од. лимонаду і 20 од. соку, сумарно 50 од.).

### Завдання 2 — інтеграл методом Монте-Карло

- `task-2.py` оцінює інтеграл `∫_a^b x^2 dx` методом Монте-Карло (кількість вибірок задається параметром), будує графік області інтегрування та порівнює результат із `scipy.integrate.quad`.
- Виводиться емпіричне значення, точне розв'язання та абсолютна похибка; похибка зменшується зі збільшенням кількості вибірок.
- У прикладі при 10 тис. точок оцінка близька до точного значення 8/3, що підтверджує коректність алгоритму.

### Запуск

```bash
cd goit-algo-hw-10
python3 -m venv venv && source venv/bin/activate
pip install pulp numpy matplotlib scipy
python3 task-1.py
python3 task-2.py --samples 10000
```
